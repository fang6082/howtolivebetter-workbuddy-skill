# 性价比档位算法（照书原版抄录）

来源：仓库 `index.html` 第 615 行与第 1034 行，逐字抄录，别凭记忆改。

## 成本分（cs）

三项成本各档的权重，成本分 = 钱档 + 时间档 + 毅力档 相加：

```
COST_W = {
  money: {'0': 0, '少': 1, '多': 2},
  time:  {'少': 0, '中': 1, '多': 2},
  will:  {'否': 0, '些': 1, '是': 2},
}
```

## 收益量级 × 成本分 → 性价比档

```
收益=大：cs = 0 → 极高；cs ≤ 2 → 高；其余 → 一般
收益=中：cs = 0 → 高；其余 → 一般
收益=小：一律 一般
```

原文（JavaScript）：

```js
e.cs = COST_W.money[e.money] + COST_W.time[e.time] + COST_W.will[e.will];
e.ratio = e.level === '大' ? (e.cs === 0 ? '极高' : (e.cs <= 2 ? '高' : '一般'))
        : e.level === '中' ? (e.cs === 0 ? '高' : '一般') : '一般';
```

## 使用规则（承袭原 skill）

1. 先按性价比档（极高 > 高 > 一般），同档再按证据等级 A > B > C，再按跟用户处境的贴合度。
2. **不同口径之间不排序**：换钱的和换寿命的分开列，各排各的。
3. 「一般」不等于不该做，只是那笔花销得用户自己掂量。性价比是作者的判断，按书自己的标准只算 C 级，和证据等级是两回事。
